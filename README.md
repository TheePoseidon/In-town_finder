# In-town Finder

> Locate and navigate to essential services and lifestyle destinations in Kigali, Rwanda.

## About

**In-town Finder** is a Flutter mobile application built for Kigali residents. It lets users quickly find hospitals, police stations, public libraries, utility offices, restaurants, cafés, parks, and tourist attractions — all on an interactive map with one-tap directions.

## Repository Structure

